## Context

When a terminal is spawned during session restore, it needs the active worktree's path as its cwd. The renderer hook `useActiveWorktreeSync` was emitting the cwd before the worktrees list had finished loading from the store.

## Problem

On cold start the worktrees store is empty initially. `useActiveWorktreeSync` fired immediately, emitting a cwd derived from a stale `homeDir` fallback. The spawned terminal opened in the user's home directory instead of the project worktree.

A secondary gap existed in the main process: the terminal spawn handler (`electron/ipc/handlers/terminal/lifecycle.ts`) also fell back to `os.homedir()` when it couldn't resolve a usable cwd at spawn time.

## Root cause

Two independent race windows:

1. **Renderer**: no `isInitialized` guard — the hook emitted a path event as soon as it mounted, before the worktree list had hydrated.
2. **Main process**: the fallback chain in the spawn handler went straight to `os.homedir()` without first attempting to resolve a real working directory (the resolved worktree path passed from the renderer, or the project path).

## Lesson

Hooks that derive paths from async-loaded store data must gate their output behind an `isInitialized` flag. Emitting before the store slice is loaded produces a valid-looking but stale value.

In the main process, exhaust real working-directory candidates (the resolved cwd from the renderer, then the project path, validated with a filesystem `access` check) before falling back to `os.homedir()`. The current spawn handler (`electron/ipc/handlers/terminal/lifecycle.ts`) resolves `cwd = validatedOptions.cwd || projectCwd || projectPath || os.homedir()` and revalidates against the filesystem rather than doing an async worktree lookup at spawn time.

## Applies when

- Any hook that reads from a store slice populated by IPC/async hydration and emits an event or side-effect on initial render.
- Any main-process spawn path with a `os.homedir()` fallback — exhaust real cwd candidates (renderer-supplied path, project path) first.
