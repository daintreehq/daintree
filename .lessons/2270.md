## Context

The hybrid input bar computes how many lines its content occupies by dividing the editor content height by a constant `LINE_HEIGHT_PX` and uses the result to size the collapsed height. (The input bar has since migrated from a textarea to a CodeMirror editor; the auto-size logic now lives in the `computeAutoSize`/`createAutoSize` extension in `src/components/Terminal/inputEditorExtensions/base.ts`.)

## Problem

At non-100% browser zoom (50%, 125%, 150%, 200%) the empty input bar rendered taller than one line and grew unevenly as lines were added. Scrollbars flickered near the max boundary.

## Root cause

Browser zoom scales computed `lineHeight` by a fractional factor — `20px` becomes `25.333px` at 125%. Dividing `scrollHeight` (also fractional) by a hardcoded integer `LINE_HEIGHT_PX = 20` returns more than 1 for a single empty line due to rounding error. `Math.ceil` then inflates the displayed line count. Empty documents in particular had `scrollHeight > 0` from baseline metrics even with no text.

## Lesson

For any DOM-based line or row counting: read the actual line height from the measurement layer (the editor's `view.defaultLineHeight` for CodeMirror, or `getComputedStyle(...).lineHeight` / a test element for raw DOM), never hardcode pixel constants — keep any hardcoded value (`LINE_HEIGHT_PX`) only as a last-resort fallback. Subtract a small epsilon (`EPSILON_PX = 2`) from the measured content height before dividing so rounding error does not tip a count over a threshold, and align scroll-state thresholds with the same epsilon to avoid scrollbar flicker at max. Short-circuit the empty-document case to return one line directly — do not depend on the measurement path to produce that answer. (`computeAutoSize` uses `Math.ceil` after subtracting the epsilon; the epsilon absorbs the fractional-zoom rounding the ceil would otherwise inflate.)

## Applies when

Implementing auto-resizing inputs, scroll-to-line logic, or any DOM measurement that must be accurate across user zoom levels and display DPI.
