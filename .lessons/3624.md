## Context

Electron renders a blank white (or black) window during the period between `show` and the first React render completing. This is especially visible on first launch or after cache invalidation when V8 compilation takes longer.

## Problem

Users saw a blank window for a perceptible period at startup, giving the impression of a slow or broken app.

## Lesson

Inline a skeleton UI directly in `index.html` using CSS custom properties that match the app's theme tokens. The skeleton loads with zero JavaScript, appearing the instant Chromium paints the first frame.

Key implementation details:

1. Use CSS custom properties for colors (`var(--theme-surface-*)`) so the skeleton respects both light and dark themes without JavaScript.
2. Gate the skeleton's entrance behind the 400ms Doherty anti-flicker threshold rather than showing it immediately — the container animation uses `animation-fill-mode: backwards` with a 400ms delay (`skeleton-doherty-gate` in `index.html`) so sub-threshold loads never flash a skeleton, then fades in over 200ms. (The original PR used `forwards`/immediate visibility; that was reversed to honor the app-wide Doherty gate. A visible stuck-state overlay surfaces at 6s.)
3. Remove the skeleton after React's first render via `removeStartupSkeleton()` (`src/utils/removeStartupSkeleton.ts`): a double `requestAnimationFrame` waits for React's paint, then prefers the View Transitions API for a GPU crossfade, falling back to a plain CSS `.fade-out` opacity transition under reduced-motion / performance mode / older runtimes.
4. Make the removal idempotent — the element may already be gone if called twice (`removeStartupSkeleton` no-ops when the node is absent).
5. Call the removal utility from `App.tsx` `useEffect` on mount (gated on hydration / pending-crash state).

The skeleton layout should approximate the real app structure (sidebar, toolbar, main content) to avoid a jarring layout shift when the real UI appears.

## Applies when

- Reducing perceived startup time for Electron apps
- Any BrowserWindow that shows a blank period before the React app renders
- Adding a new top-level window with a distinct layout
