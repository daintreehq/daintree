## Context

Project Pulse renders a commit heatmap. `ProjectPulseService.getFirstCommitDate` (`electron/services/ProjectPulseService.ts:679`) finds the repo's first commit so `getPulse` can mark heatmap cells before that date as `isBeforeProject` and cull them (`ProjectPulseService.ts:324-343`).

## Problem

In a shallow clone the heatmap rendered blank even though the repo had recent commits — nearly every cell was marked `isBeforeProject` and filtered out.

## Root cause

A shallow clone records its boundary commits in `.git/shallow`; git treats those grafted commits as parentless. So `git rev-list --max-parents=0 HEAD` returns the shallow-boundary SHA (often only days old), NOT the true historical root commit. `getFirstCommitDate` trusted that SHA's timestamp, producing a `firstCommitDate` that was a few days ago. Every cell older than that boundary then satisfied `cell.date < firstCommitDay` and got `isBeforeProject = true`, collapsing the heatmap to a couple of cells.

## Lesson

"First commit" / "project age" derived from `rev-list --max-parents=0` is only correct in a full clone. Probe `git rev-parse --is-shallow-repository` first; if it returns `"true"`, you cannot know the real root — return `null` and let the caller fall back (here `projectAgeDays` falls back to `rangeDays` and no cells are culled). Two sharp edges: (1) pre-2.15 git doesn't know the flag and echoes it back verbatim, so a strict `=== "true"` check (not "contains true") naturally falls through to the normal non-shallow path — see the old-git fallback test; (2) the `null` return must already be a safe no-cull path in the caller, which it is via the `if (firstCommitDate)` guard at `ProjectPulseService.ts:325`.

## Applies when

Any code computes repo age, first-commit date, full history streaks, or "before project start" markers from `rev-list --max-parents`, `git log --reverse`, or root-commit lookups — and the repo could be a shallow or partial clone (CI checkouts, `clone --depth`, blobless/treeless partial clones all distort the visible root).
