## Context

When the worktree sidebar was shown or hidden, all visible terminals were resized as the grid reflowed. Codex CLI interprets a PTY `SIGWINCH` resize signal as a prompt to enter interactive mode, disrupting an in-progress agent run.

## Problem

The sidebar uses a CSS transition (smooth animation), so during the animation the terminal dimensions change continuously. Each intermediate size emitted a PTY resize to all running processes. Codex CLI specifically treats a resize signal as user intent to enter interactive mode.

## Root cause

`TerminalResizeController` was firing `fit()` on every ResizeObserver callback during the CSS transition. There was no concept of "layout is transitioning — hold resize signals."

## Lesson

Any animated layout change (sidebar toggle, panel split, drag resize) that changes terminal container dimensions must gate PTY resize propagation. The fix pattern (now a per-terminal resize lock rather than a single global flag):

1. Lock affected terminals at transition start via `terminalInstanceService.lockResize(id, true, ttlMs)` (TTL matched to the transition duration). The sidebar case wraps this in `suppressSidebarResizes()` (`src/lib/sidebarToggle.ts`), which calls `suppressResizesDuringLayoutTransition(ids, SIDEBAR_TOGGLE_LOCK_MS)`.
2. In `TerminalResizeController.fit()`, early-return when `isResizeLocked(id)` is true so no resize IPC fires mid-transition.
3. When the lock TTL elapses (or `lockResize(id, false)` is called), flush a single resize with the final dimensions.

This reduces N intermediate `SIGWINCH` signals to exactly 1 final signal. The lock TTL (`SIDEBAR_TOGGLE_LOCK_MS` in `src/lib/terminalLayout.ts`) must be kept in sync with the CSS transition duration.

CLI tools that interpret `SIGWINCH` as interaction signals (Codex, some ncurses apps) are sensitive to spurious resizes. Any Electron app with animated layout transitions containing terminal panels needs this pattern.

## Applies when

Any layout animation that resizes terminal panels: sidebar toggle, panel split/join, window resize with transitions, responsive layout changes.
