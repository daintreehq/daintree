## Context

The worktree diff viewer (`DiffViewer.tsx` + `react-diff-view`, syntax via `refractor`) got a two-PR overhaul: #10349 added pinned gutters, wrap/ignore-whitespace toggles, hunk navigation and a 1MB backend size guard; #10354 followed with centered split scrolling, moved-code detection, and in-diff search — fixing several silent render bugs along the way. That tokenization/cache code has since moved out of `DiffViewer.tsx` into `diffRefractor.ts`, `diffTokenizer.ts`, `diffTokenizePipeline.ts`, and `src/panels/diff/diffContentCache.ts` (the old `FileDiffModal` is now a diff panel), but every mechanism below is intact in the current tree.

## Problem

Syntax highlighting and word-level change highlighting had never actually rendered in diffs — no error, no warning, just plain-text diffs everyone assumed were correct. Separately: once highlighting worked the edit pills were an unreadable pale green/pink on dark themes; pinned gutters lost their border during horizontal scroll; and toggling ignore-whitespace left the previous flag's diffs cached for the rest of the session.

## Root cause

`react-diff-view`'s `tokenize` (now the custom `tokenizeFast` in `diffTokenizePipeline.ts`) expects **refractor v3's `highlight()` contract — a plain array of hast nodes**. refractor v4+ returns a hast **`Root` object** whose non-iterable shape makes the token tree-walk throw; `runDiffTokenize`'s `catch` turned that throw into `tokens = null`, which the renderer treats as "no tokens" and falls back to plain text — killing syntax highlighting, word-level edit pills, AND search marks with zero surfaced error. The fix is the tiny `refractorAdapter` in `diffRefractor.ts` wrapping `refractor.highlight(...).children` to restore the v3 array shape; #10354 also added `console.warn("Diff tokenization failed", err)` in the catch so this failure can never be silent again.

Once tokens rendered, the pills used react-diff-view's `--diff-code-{insert,delete}-edit-background-color` **`:root` defaults, which are GitHub-light hex `#c0dc91` / `#f39ea2`** — invisible on a dark canvas. The pinned gutters use `position: sticky`; under `border-collapse: collapse` **Chromium detaches cell borders from sticky cells during horizontal scroll**, so the gutter's 1px separator vanished mid-drag. And the session diff cache keyed entries without the ignore-whitespace flag, so a whitespace-toggled diff and its opposite collided.

## Lesson

- **When wiring `refractor` into `react-diff-view` (or bumping either), assume the shapes disagree: refractor v4+ returns a hast `Root`, the tokenizer wants an array.** Keep `refractorAdapter` (unwrap `.children`) — dropping it produces no error, just silently-plaintext diffs. Any `catch` in a tokenize/highlight path must `console.warn`, never swallow to null: a null token pass degrades highlighting + edit pills + search marks at once with no visible signal (`diffTokenizer.ts` `runDiffTokenize`).
- **Override a bundled diff/highlight library's edit colors by re-declaring its CSS variables scoped to your container, not by chasing element classes.** react-diff-view renders `span.diff-code-edit` (there is NO `.diff-code-insert-edit` element class); it reads the pill color only through `--diff-code-{insert,delete}-edit-background-color`. Setting those on `.diff-viewer` beats the lib's `:root` defaults regardless of stylesheet load order, so the override can't regress on specificity. Use `color-mix(in oklch, var(--color-status-success|danger) 40%, var(--color-daintree-bg))` so the pill stays anchored to the theme canvas and never costs syntax-text contrast.
- **`position: sticky` table cells require `border-collapse: separate; border-spacing: 0` on Chromium** — under `collapse`, sticky cell borders detach and disappear during horizontal scroll. This is why `table.diff` in `DiffViewer.css` is `separate`; do not "tidy" it back to `collapse`.
- **Any diff cache key must include every flag that changes git's output.** `diffCacheKey` in `diffContentCache.ts` appends `String(ignoreWhitespace)` as its last (`\u0000`-delimited) segment, and `purgeOtherWhitespaceEntries` drops entries built under the other flag on toggle — otherwise a `--ignore-all-space` diff and a full diff share a key and serve each other's stale content. Base-branch diffs are deliberately NOT cached: their key is branch _names_ (not content identity), so a reopen after the base advances would serve a stale diff the freshness signal can't catch.

## Applies when

- Touching diff tokenization (`diffRefractor.ts`, `diffTokenizer.ts`, `diffTokenizePipeline.ts`) or bumping `refractor` / `react-diff-view` — verify the `refractorAdapter` `.children` unwrap still matches refractor's output shape and that highlighting actually renders, not just that the build passes.
- Diffs (or any react-diff-view surface) render as plain text with correct content but no colors, no word-level pills, and no search marks — suspect a swallowed tokenize throw, not missing grammars; grep for `Diff tokenization failed` in the console.
- A bundled highlight/diff library's colors look wrong on dark themes (e.g. pale GitHub-light green/pink) — re-declare its CSS custom properties scoped to your wrapper rather than targeting its element classes.
- Building any `position: sticky` table cell (pinned gutter, frozen header/column) in this Chromium-only app — it needs `border-collapse: separate; border-spacing: 0` or borders drop during scroll.
- Adding or reviewing a content cache keyed on git output (`diffContentCache.ts`) — the key must carry every flag (`--ignore-all-space`, merge-base, status) that alters the result, and branch-name keys are not safe to cache.
