## Context

Vite 8 ships with Rolldown as the bundler (replacing Rollup). The migration required updating the code-splitting API and the console stripping mechanism.

## Problem

Two API changes broke the existing Vite 6 config:

1. `build.rollupOptions.output.manualChunks` is deprecated/removed in Vite 8 — Rolldown uses a different code-splitting API
2. `esbuild.pure` (used to strip `console.*` calls) is not available under Rolldown — it uses its own tree-shaking mechanism

## Root cause

Vite 8 / Rolldown is a significant architectural change — Rolldown has its own chunking API (`build.rolldownOptions.output.codeSplitting`) that differs from Rollup's `manualChunks`. Console stripping via `esbuild.pure` worked in Vite 6 because esbuild was the transformer; Rolldown has its own equivalent.

## Lesson

When migrating to Vite 8:

- Replace `rollupOptions.output.manualChunks` with `build.rolldownOptions.output.codeSplitting.groups` using named test-matched groups (see `vite.config.ts`):

  ```ts
  build: {
    rolldownOptions: {
      output: {
        codeSplitting: {
          groups: [
            { name: "vendor-react", test: /node_modules[\\/]react/, priority: 15 },
            // ...
          ],
        },
      },
    },
  }
  ```

- Replace `esbuild.pure: ['console.log', ...]` with Rolldown's tree-shake pure-functions list (gated to production builds in `vite.config.ts`):

  ```ts
  build: {
    rolldownOptions: {
      treeshake: {
        manualPureFunctions: ["console.log", "console.info", "console.warn", "console.debug"],
      },
    },
  }
  ```

- Anchor regex patterns in code-splitting group `test` matchers (`/node_modules[\\/]…/`) to avoid false matches outside `node_modules`

Note: as of the current config, the React Compiler runs via `@rolldown/plugin-babel` + `reactCompilerPreset` (not a pure-Oxc transform), so the compiler still flows through a Babel-style plugin pipeline alongside `@vitejs/plugin-react`.

## Applies when

Upgrading from Vite 6 to Vite 8 in any Electron or web project using custom chunk splitting or console stripping.
