## Context

Agents were showing "failed" state after Ctrl+C, SIGTERM, and other routine user-initiated exits.

## Problem

`isRoutineExit()` in `terminalForensics.ts` had **inverted boolean logic** — it returned `true` for crash scenarios and `false` for routine exits, the opposite of its name. This caused SIGINT (130), SIGTERM (143), and SIGHUP (129) to be classified as non-routine, triggering the failed state.

Additionally, the agent state machine of the time had no recovery path from its terminal failure state: once there, subsequent activity events were ignored. (The FSM has since been redesigned — see Lesson.)

## Root cause

A logic inversion bug in the forensics classifier. Since the function name was `isRoutineExit`, the caller correctly passed its return value to "is this OK to ignore", but the function body returned the wrong polarity. Tests were written to match the (wrong) behavior rather than catching the inversion.

## Lesson

Boolean classifier functions where the name says "is routine" must return `true` for the routine/expected case. When writing tests for these functions, test against known-good inputs (e.g., SIGINT should definitely be routine) rather than only testing the implementation's current output. `isRoutineExit()` in `terminalForensics.ts` now correctly returns `false` only for `CRASH_SIGNALS` (SIGILL/SIGABRT/SIGBUS/SIGFPE/SIGKILL/SIGSEGV) and otherwise `true`; SIGINT/SIGTERM/SIGHUP/SIGPIPE live in `EXPECTED_TERMINATION_SIGNALS`.

Also: state machines should always have recovery paths — a terminal failure state with no exit is a UX trap. The agent FSM has since been rebuilt around `idle | working | waiting | directing | completed | exited` (`shared/types/agent.ts`, transitions in `shared/utils/agentFsm.ts`); there is no longer a `failed` state, and the terminal `exited` state has an explicit recovery path (`exited: ["idle"]`, respawn into a fresh agent session in the same PTY).

## Applies when

- `terminalForensics.isRoutineExit()` or `decideTerminalExitForensics()`
- Agent state machine transitions out of terminal states (`exited` recovery in `shared/utils/agentFsm.ts`)
- Debugging "agent shows failed/stuck after Ctrl+C or normal exit"
